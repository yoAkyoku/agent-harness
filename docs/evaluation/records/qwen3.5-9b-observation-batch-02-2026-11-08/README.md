## 解讀

- **完成回覆檢查達成目標**：回覆從「重述任務」變成「描述這份成果」，三個分析案例全部正確。
- **它的邊界也很清楚**：它保證回覆和成果一致，但無法修正成果本身的錯誤。剩下兩個不接受的案例，回覆都忠實轉述了錯誤的成果。
- 剩下的兩個問題都在成果層：誤讀任務結構（`documents-standard`），以及用另一個角色的人名填補缺少的欄位（`documents-missing`）。後者可能做成不讀任務文字的證據檢查（正文填入的值，若在來源中只出現在另一個標籤之後就回饋），但需要先確認不會誤殺正確內容；前者屬於任務理解，較難在不讀任務文字的前提下偵測。
