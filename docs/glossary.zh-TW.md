# Agent Harness Demo

使用者交代任務，由 Agent 在明確工作範圍內執行工具、保存背景並交付可檢查成果的工作空間。

## Language

**Workspace（工作區）**：使用者選定的工作範圍，包含可用來源、Session、記憶與成果。

**Task（任務）**：使用者提出的一次需求及輸入。

**Session（對話）**：一組可接續 Task 的共同背景與紀錄；它的存在不代表某個 Run 仍在執行。
_Avoid_: 將 Session 與登入狀態、持久記憶或中斷 Run 恢復混用。

**Run（執行）**：一個 Task 在固定設定與限額下展開的執行實例，具有獨立狀態、事件及結果。

**Plan（計畫）**：Run 向使用者呈現的工作步驟與進度，可根據新的執行結果更新。
_Avoid_: 把可見計畫當作模型內部思考鏈。

**Source（來源）**：工作區內具有穩定身分、內容版本與可定位內容的輸入資料。

**Tool（工具）**：Agent 可請求執行的具名能力，具有可接受輸入與可檢查結果。

**Tool Attempt（工具嘗試）**：對某個具體工具請求的一次處理，包含派發與效果是否已確認的紀錄。

**Action Approval（操作確認）**：使用者對一次具體工具操作及其參數的同意。
_Avoid_: 把單次確認當成永久授權或可繞過工作區限制的許可。

**Context（上下文）**：為某次模型請求選入的任務、指令、歷史、記憶及來源片段，與保存的全部歷史不同。

**Memory（記憶）**：使用者明確保存、可跨 Session 選用的偏好或事實，帶作用範圍、來源與版本。
_Avoid_: 把完整對話歷史或工具權限稱為 Memory。

**Run Event（執行事件）**：Run 中可保存、查回並供使用者檢查的狀態變化、動作或結果。

**Artifact（產物）**：Run 發布的具名成果版本；修改建立新版本，原版本仍可檢查。

**Checkpoint（續做依據）**：執行中已確認結果與剩餘工作的可驗證紀錄。
_Avoid_: 把 Checkpoint 當成可回滾外部副作用的電腦快照。

**Recovery（恢復）**：辨識中斷與未知效果後，以明確的新 Run 接續可驗證工作，而非重播所有舊操作。
